# TaskNest 📝

TaskNest is a simple task management application that helps users organize and manage their daily tasks. It implements basic CRUD (Create, Read, Update, Delete) operations, allowing users to create tasks, view their task list, edit task details, and delete tasks when they are no longer needed.

## Features

- **Create Tasks:** Add new tasks with a name and description.
- **View Tasks:** Display all created tasks.
- **Update Tasks:** Edit existing task details.
- **Delete Tasks:** Remove tasks from the task list.
- **Simple Interface:** Manage tasks through an easy-to-use interface.

## CRUD Operations

| Operation | Description |
|---|---|
| Create | Add a new task. |
| Read | View the list of tasks and their details. |
| Update | Modify an existing task. |
| Delete | Remove a task permanently. |

## Application Flow

1. Open TaskNest.
2. Add a task by entering its name and details.
3. View the tasks in the task list.
4. Edit a task whenever its details change.
5. Delete tasks that are no longer required.
